# Planted items

Generated by `make docs` from `platform/planted/registry.yaml`. Edit that file, not this page.

Every demo shows its teaching moment because something guarantees it, and this page lists what.
Each item is off by default, so the default path is the fixed, honest system. When an item is on,
the console's status line shows a chip for it. The items write Structured Query Language (SQL),
JavaScript Object Notation (JSON), and Coordinated Universal Time (UTC) by their short forms.

> **Terms on this page**
>
> - **Planted bug**: A defect switched on by a flag so a demo shows its failure every time.
> - **Harness weakness**: Part of the starting configuration that a later loop fixes.
> - **Data condition**: A property of the seeded data that changes a naive answer.
> - **Demo aid**: A labelled setting that makes a live run easier to watch, never its result.

## Code bugs

### The unbounded rows bug

- **Identifier**: `BUG_UNBOUNDED_ROWS`
- **Section**: Section 1: Agent loop
- **Where**: `platform/src/datapilot/loop1_agent/tools.py`
- **Trigger**: `make demo NAME=agent-unbounded-rows PLANTED=1` (its own run only)
- **Symptom**: run_query returns every row; a 10,000-row result reaches the model and tokens spike.
- **Fix**: Cap rows at limits.row_cap, return the total row count and a truncation notice.
- **Demos**: Unbounded rows (`agent-unbounded-rows`)

### The names-only schema

- **Identifier**: `BUG_NAMES_ONLY_SCHEMA`

- **Trigger**: BUG_NAMES_ONLY_SCHEMA=1, then Agent > Ask
- **Symptom**: describe_table returns column names only, so the analyst misreads columns.
- **Fix**: Return types, nullability, neutral comments, 3 sample rows, and distinct values for low-cardinality columns.

### The naive guard

- **Identifier**: `BUG_NAIVE_GUARD`
- **Section**: Section 2: Verification loop
- **Where**: `platform/src/datapilot/loop2_verification/graders/statement_policy.py`
- **Trigger**: `make demo NAME=verify-malicious-sql PLANTED=1` (its own run only)
- **Symptom**: A prefix check (the text starts with select or with) passes "SELECT 1; DELETE FROM orders" and a data-modifying CTE; only the read-only role stops them.
