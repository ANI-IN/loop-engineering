# Before-class records

The results recorded before class, which the console shows next to every new run, always
labelled "before class". One file per recorded run, written by the tool, never edited by hand.

- Record each section's runs with the settings the class uses, and keep every run, including the
  ones that did not go the course's way.
- The headline measure of each section is fixed in `platform/config/measures.toml` before the
  first run.
- Timings count only runs that ran alone on the machine.
