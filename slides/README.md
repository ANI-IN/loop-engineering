# Module: Loop Engineering - Slides

The class deck is handed out separately, not kept in this folder. This folder holds the deck's
outline, [outline.md](outline.md): every slide's title, text, links and speaker notes, generated
from the final class deck (`platform/scripts/outline_from_deck.py`, run by `make outline`) and
never edited by hand.

**`source/` is superseded.** The Python files in `source/` built earlier versions of the deck and
its outline. Since 28 October 2026 the class deck is a final, hand-edited file, and the outline
comes from it, never from `source/`; the files stay for reference only. The design system and the
schema they followed are in [design-system.md](design-system.md).
